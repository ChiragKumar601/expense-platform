## Prompt Development Log

All significant Claude Code prompts used during development must be recorded
in:

`prompts/development-log.md`

For each significant development interaction:

1. Preserve the important prompt/instruction.
2. Record the purpose.
3. Record the resulting decisions.
4. Record relevant artifacts or files changed.

Do not record secrets, credentials, tokens, API keys, or other sensitive data.

The prompt log is a historical development record. It is not a source of
product requirements or implementation truth.

The authoritative artifacts remain:

- `intent/intent.md` — product intent
- `docs/glossary.md` — domain terminology
- `docs/domain.md` — domain model
- `docs/architecture.md` — architecture
- `specs/` — approved product specifications
- `tickets/` — implementation work
- `plans/` — implementation plans
